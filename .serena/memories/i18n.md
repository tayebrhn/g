# Internationalization (i18n) & UI text

## Mechanism
- Strings come from TMX resources (`shared/config/lang/language_tmx.xml`), loaded by `shared/code/tce_tmx.php` into the global **`$l`** array; classes cached under `cache/lang/`.
- `K_PATH_TMX_FILE` points at the TMX; `K_USER_LANG` (2-letter) selected from `?lang=`, `SessionUserLang` cookie, else `K_LANGUAGE`. `K_AVAILABLE_LANGUAGES` is a serialized array (currently only `en`). `K_LANGUAGE_SELECTOR` toggles the picker.
- **Never hardcode user-facing text.** Use `$l['key']`. Hardcoded English in PHP/HTML is a defect (the audit fixes 3 such strings).

## Key prefixes (convention)
- `a_*` — meta/attributes (`a_meta_charset`, `a_meta_language`, `a_meta_dir`).
- `t_*` — page/section titles.
- `w_*` — words/labels/buttons.
- `h_*` — tooltips/field help.
- `hp_*` — help paragraphs / longer help text.
- `m_*` — messages and errors. `w_level_*` — user-level labels (see `mem:auth`).

## UI-text style rules
Authoritative glossary + style guide: `UX_CONTENT_AUDIT.md`. Summary:
- Sentence case everywhere (titles, buttons, labels, status). Brand/domain terms keep casing (TCExam, OMR, OTP, SSL, PDF, TSV, CSV).
- No ALL CAPS messages; errors state the problem then the fix; destructive confirmations name the object + consequence + permanence ("... This cannot be undone.").
- One action, one label: `edit` (not modify), `upload` (not send), `start test`/`end test` (not execute/terminate for candidates), `delete`, `log in`/`log out`.
- UI uses **topic** for what the DB calls *subject*; `test` not `exam`; `last name`/`first name`; `email`; US spelling (`license`, `cataloged`).
- Keep placeholders/entities/format tokens intact (`[delete]`, `#TCEXAMURL#`, `&lt;br /&gt;`, trailing `: ` before appended values). Keep strings short (translation expansion).
- Render-time escaping: `htmlspecialchars($s, ENT_NOQUOTES, $l['a_meta_charset'])`.

## Encoding
All files/labels UTF-8. RTL supported via `$l['a_meta_dir']` and `*_rtl.css`. Normalization mode for question/answer text: `K_UTF8_NORMALIZATION_MODE` (NONE by default).
